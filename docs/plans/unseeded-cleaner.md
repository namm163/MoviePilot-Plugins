# 未做种清理插件（unseededcleaner）设计文档

> 状态：设计已确认，待实现
> 日期：2026-09-06

## 背景与目标

PT 下载内容直接落在媒体库目录（`/media*/movie`、`/education` 等）中做种。当种子从
Transmission 中删除但保留了文件时，这些内容留在磁盘上不再产生任何价值，却占用大量空间。

本插件用于**扫描磁盘上已不在 Transmission 做种的内容**，在插件页面集中展示，
支持勾选后直接删除，释放磁盘空间。

## 需求决策记录

| 决策点 | 结论 |
|---|---|
| 识别依据 | 用户指定下载根目录列表，只扫描这些目录（范围最小最安全） |
| 操作能力 | 展示 + 手动勾选删除，带二次确认 |
| 删除方式 | 直接删除磁盘文件（不走回收站） |
| 触发方式 | 仅手动触发（页面按钮），无定时任务 |
| 进度反馈 | 状态持久化，重开页面可见；两段式扫描让名单秒级可见，大小后台补全 |
| 通知 | 扫描完成消息通知，可配置，默认关闭 |
| 开关 | 无 enabled 开关（无后台常驻逻辑） |
| 下载器 | 仅支持 transmission（取 MoviePilot 已配置的 Tr 实例） |

## 可行性调研结论（NAS 实测）

- **路径零映射**：MoviePilot 容器与 transmission 容器挂载点完全一致
  （`/media`~`/media6`、`/downloads`、`/education`），Tr RPC 返回的 `downloadDir`
  在插件内直接可用。
- **RPC 能力**：`get_torrents()` 一次拿全量种子（含 `downloadDir`、`name`、
  `hashString`、`totalSize`；含下载中/暂停状态，天然保护未完成下载）。
- **存储结构**：`/downloads` 仅剩 10G 临时文件，PT 内容实际在 `/media*/movie`、
  `/media*/series`、`/media4/9kg`、`/education` 等目录。
- **插件机制**：v3 插件 `get_page`（Vuetify 拼装详情页）+ `get_api`（自定义接口）
  + `events.click.api` 前端调后端交互均有成熟先例（doubansync、animeupscale 等）。
- **限制**：`/adult` 仅 Tr 挂载、MoviePilot 容器未挂载，插件扫描范围不含它
  （如需覆盖须先给容器加挂载并重启）。
- **页面无自动轮询**：`get_page` 为服务端拼装静态配置，页面打开时渲染一次；
  进度反馈靠持久化状态 + 手动刷新（见两段式扫描）。

## 总体架构

方案：**目录级内容单元 + 双向前缀匹配 + 轻量 Vuetify 页面**（纯 Python 单文件，
无 Vue 构建链）。

```
插件 unseededcleaner（plugins.v3/unseededcleaner/__init__.py）
│
├─ get_form()               配置页：下载根目录列表 + 排除关键字
├─ get_page()               详情页：状态卡片 + 按根分组的结果表格
├─ get_api()                scan / status / delete 三个接口
│
├─ __get_protected_paths()  Tr 全量种子 → 保护路径集合（规范化）
├─ __scan()                 两段式扫描（后台线程）
├─ __size_units()           第二段：逐单元统计大小（后台渐进填充）
└─ __delete()               删除选中项（四道安全校验，后台线程）
```

## 详细设计

### 配置项（get_form）

| 键 | 说明 |
|---|---|
| `scan_dirs` | 下载根目录列表，每行一个。**必须配到"种子直接存放的那一层"**（如 `/media4/9kg`、`/education`；配 `/media4` 会导致粒度错误） |
| `exclude_keywords` | 额外排除关键字（内置硬排除：`incomplete`、`.trash`、`@eaDir`、`#recycle`） |
| `notify` | 扫描完成消息通知（默认关闭；开启后走 MoviePilot 已配置的通知渠道） |

无 enabled、无下载器选择、无定时配置。

### 持久化数据（save_data / get_data）

```python
# 1. 动作状态（页面重开后恢复显示）
action_status = {
    "action": "scan" | "delete",
    "status": "running" | "done" | "error",
    "progress": "已扫描 12/48 个目录，正在统计大小…",
    "total_size": "可释放 356.2 GB",
    "started_at": "...", "finished_at": "...",
}

# 2. 扫描结果（两段式渐进填充）
last_scan = {
    "scan_time": "2026-09-06T15:30:00",
    "tr_torrent_count": 1234,        # Tr 当前种子总数（信息展示）
    "roots": [
        {"root": "/media4/9kg", "units": [
            {"path": "/media4/9kg/xxx-HDSky", "name": "xxx-HDSky",
             "type": "dir" | "file",
             "size": 42100000000,     # 未统计完为 None
             "sized": true},          # 大小是否已统计
        ]},
    ],
}

# 3. 删除记录（append-only，保留最近 500 条）
delete_log = [{"path": "...", "size": ..., "time": "..."}]
```

### 扫描与对比算法（两段式）

```
第一段（秒级，产出名单）：
  ① get_torrents() 全量一次 → 每个种子 protected = normpath(join(downloadDir, name))
     → 保护路径集合（RPC 出错 → 立即中止，本次不产出任何结果）
  ② 对每个扫描根目录 scandir 一级子项 = 内容单元：
     - 命中排除关键字 → 跳过
     - OSError → 标记「无法读取」，不进入可删列表
  ③ 双向前缀匹配判定（单元路径 U vs 保护路径 P）：
     - P 以 U 开头 → 种子在该单元内部 → 保护
     - U 以 P 开头 → 单元在种子路径内部 → 保护
     - 两者皆无 → 未做种 ✗
  ④ 结果立即持久化（size=None, sized=false），页面刷新即见名单

第二段（后台，分钟级）：
  ⑤ 逐单元 walk 统计大小（目录递归 / 文件 stat），边统计边更新 last_scan
  ⑥ 全部完成 → 更新 action_status，可选发消息通知
```

- 路径统一 `normpath` + `realpath` 后比较（处理尾斜杠、符号链接）。
- 性能：RPC 一次调用；前缀匹配为内存字符串运算（几百单元 × 几千种子，秒级内）；
  唯一大头（大小统计）被隔离在第二段后台。

### 页面（get_page）

```
┌────────────────────────────────────────────────┐
│ 状态卡片：扫描中/删除中显示 VProgressLinear 进度；  │
│ 完成显示结果摘要（项数、可释放空间、时间）           │
├────────────────────────────────────────────────┤
│ [立即扫描]  [刷新]                 [删除选中(N)] │
├────────────────────────────────────────────────┤
│ 按扫描根分组（每组一张卡片，卡片头：根路径 +         │
│ 该组未做种数量/大小合计）                           │
│ 组内 VDataTable：☑ │ 名称 │ 大小 │ 类型 │ 路径      │
│ 自带分页（默认每页 50）与排序（大小/名称）           │
├────────────────────────────────────────────────┤
│ 底部：已选 N 项合计 XX GB；删除记录可展开查看        │
└────────────────────────────────────────────────┘
```

- 表格行数 = 未做种**内容单元**数（≈ 种子目录数，几百~几千），与磁盘文件总数无关。
- 大小未统计完的行显示"统计中…"。
- 无层级下钻（单元即种子粒度，扁平清单最直接）。

### 交互流与 API（get_api）

```
点「立即扫描」→ POST scan（后台线程启动，立即返回）→ 点「刷新」看状态/名单
勾选行 → 点「删除选中」→ VDialog 红色警告确认（列明各项与总大小）
        → POST delete {paths} → 后台线程逐项执行 → 刷新看结果
```

| 接口 | 方法 | 职责 |
|---|---|---|
| `scan` | POST | 启动扫描后台线程（线程锁互斥，进行中则拒绝） |
| `status` | GET | 返回 action_status + 结果摘要 |
| `delete` | POST | 校验 paths 后启动删除后台线程 |

### 删除的四道安全校验（按执行顺序）

1. **白名单**：API 只接受 `last_scan` 结果中存在的路径，拒绝任意路径；
2. **范围**：路径必须仍以某个配置的扫描根目录为前缀（防路径逃逸）；
3. **实时二次校验**：删除线程重新调 `get_torrents()` 重建保护集合，
   任一路径此刻被种子占用 → 跳过并标记原因（防扫描后新加种子）；
4. **只删一级子项**：`shutil.rmtree` / `os.remove` 作用于单元本身，
   绝不触碰扫描根目录本身。

### 错误处理

| 情况 | 行为 |
|---|---|
| Tr RPC 失败（扫描时） | 中止，状态卡片显示错误，不产出结果 |
| Tr RPC 失败（删除时） | 整体中止，一个都不删 |
| 单项删除失败（权限等） | 记录失败原因，继续其余项，最后汇总 |
| 重复触发扫描/删除 | 线程锁互斥，提示「正在进行中」 |
| 每次删除 | 追加 delete_log，页面底部可展开查看 |

## 已知边界与限制

1. `/adult` 不在 MoviePilot 容器挂载内，无法扫描；
2. 种子根目录改过名的场景无法匹配（"删种保文件"场景名字不变，影响极小）；
3. 页面无自动轮询，进度需手动刷新/重开页面；
4. 单元粒度 = 扫描根的一级子项，部分做种的目录整体保护（宁可不删）。
